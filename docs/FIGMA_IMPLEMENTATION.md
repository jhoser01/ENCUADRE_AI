# ENCUADRE — Figma Implementation Contract

## 1. Structure

The Figma project mirrors the design tokens and component hierarchy in code:

- **Color Variables**:
  - `Ink/950` (#080714), `Ink/900` (#100A2E)
  - `Brand/Purple-700` (#5B21E8), `Brand/Purple-500` (#7C3DFF)
  - `Brand/Green-600` (#16C95A), `Brand/Green-400` (#45E679)
  - `Surface/Light-50` (#F7F7FB), `Surface/Light-100` (#EEEEF5)
  - `Semantic/Warning` (#F5A524), `Semantic/Danger` (#E5484D)
- **Typography Styles**:
  - `Display/64` (Poppins 64/70)
  - `H1/40` (Poppins 40/48)
  - `H2/30` (Poppins 30/38)
  - `H3/22` (Poppins 22/28)
  - `Body/16` (Geist 16/24)
  - `Small/14` (Geist 14/20)
  - `Caption/12` (Geist 12/16)
- **Component Sets**:
  - `Button` (Primary, Secondary, Ghost, Danger, Icon-only)
  - `Card` (Standard, Gradient-Border, Clickable)
  - `Badge` (Active, Aligned, Waiting, Archived)
  - `AlignmentGauge` (Circular SVG ring with central score)
  - `DimensionBar` (Photographer vs Client comparative bars)
